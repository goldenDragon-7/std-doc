panel — a raised surface — lift by tone, not shadow

Even the shadow is on-brand.
When a shadow IS warranted, tint it with the accent instead of neutral black — the depth reads as part of the palette, like elements floating in a colored twilight rather than punched out of the page.

gradient-band — a quiet atmospheric wash

Atmosphere, not decoration.
Two near-neighbours of the accent, washing one direction, low and quiet. A gradient should whisper — the moment it spans the color wheel it screams crypto landing page.

howto — a titled step block with an embedded code snippet

a way to draw → add a primitive

  1. Implement the primitive contract in primitives/ — a small, pure step from data to drawn SVG, registered into the shared library. Browse the bestiary and examples/ in the repo for patterns to start from.
  2. Add a test that proves the existing pages are unchanged, and that yours renders in all three voices.
  3. Open a pull request. Reviewed, merged, and the whole library gains it at once — no forking the core, ever.
