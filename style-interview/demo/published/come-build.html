the guidelines — what every contribution holds

These aren't bureaucracy. They're the four promises that keep the gift safe to trust for the next person who opens it — the same promises that make std-doc worth giving away.

🔏
Signed & self-contained
It must freeze clean — no network, no external script, no remote font, nothing that depends on anything outside itself. The security gate refuses anything that reaches out. A gift has to work in the recipient's hands, offline, forever.
📦
Zero dependencies
Stdlib only. That's how the shipped artifact is one signed Go binary nobody has to audit a supply chain for. Your contribution keeps it that way.
🧱
It can't break anyone
The strangler proof: every document that already exists stays byte-identical after your change. You add to the vocabulary; you never alter what someone else wrote. The test suite enforces it — green stays green.
🎨
Fractal voice
A style rhymes top to bottom; a primitive reads in every voice — token-clean, zero hardcoded color. If it only looks right in one skin, it isn't finished — and yes, this page has to pass its own test in all three.
how you actually do it

a voice → add it to the Hall of Styles

  1. Drop a named :root token block into styles/ — a voice is one small block; override as few or as many tokens as the look needs (not just these three):
/* sunrise — warm, high-contrast, optimistic */
:root[data-style="sunrise"] { --bg: #fffaf3; --fg: #2a1d12; --glow: #e8590c; … }
  1. Run the suite — pytest stays green (the strangler proof).
  2. Open a pull request to the Hall. The family reviews it, merges it, and every document everywhere can now wear your voice.

a way to draw → add a primitive

  1. Implement the primitive contract in primitives/ — a small, pure step from data to drawn SVG, registered into the shared library. Browse the bestiary and examples/ in the repo for patterns to start from.
  2. Add a test that proves the existing pages are unchanged, and that yours renders in all three voices.
  3. Open a pull request. Reviewed, merged, and the whole library gains it at once — no forking the core, ever.

The repo lives on a private git today and goes public on GitHub under goldenDragon7 — a signed binary, given free. Everything above is how you walk through it.
