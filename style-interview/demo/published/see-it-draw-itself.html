best-engine-per-type routing — D2 in-process, Mermaid only where position is the meaning

A `diagram` block declares WHAT it is — a class diagram, a gantt chart, a state machine — and the library picks HOW to draw it. D2 renders in-process (pure Go, zero external tooling, even at freeze) and is the safe default. Mermaid renders in the browser and is reserved for diagrams whose meaning genuinely lives in POSITION (gantt, journey, sankey) — D2 can only encode a quantity as size, never as a computed x/y.
